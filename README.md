# Pandas Data Cleaning Project

## About the Project
This is my beginner-level Data Cleaning project using Python and Pandas in Google Colab.

The main goal of this project is to clean raw data and make it ready for further analysis.

## Tools Used
- Python
- Pandas
- NumPy
- Google Colab
- GitHub

## Operations Performed
- Loaded dataset using Pandas.
- Checked dataset structure using `head()`, `info()` and `describe()`.
- Identified missing values.
- Handled missing values using `fillna()` and `dropna()`.
- Checked and removed duplicate records.
- Used `value_counts()` to analyze categorical data.
- Cleaned column names and text values.
- Converted data types where required.
- Exported cleaned data into CSV format.

## Files Included
- `Pandas_Data_Cleaning.ipynb` – Python coding and cleaning process.
- `cleaned_data.csv` – Cleaned dataset.
- `README.md` – Project information.

## What I Learned
- Basic data cleaning with Pandas.
- Handling missing and duplicate values.
- Data type conversion.
- Working with CSV files.
- Using Google Colab for data analysis.
